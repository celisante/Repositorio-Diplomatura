# Trabajo final — Santiago Soto

Especialización comercial y concentración de las exportaciones argentinas en 2024.

## Contenido
- Trabajo_Final.qmd: informe y código.
- Trabajo_Final.html: informe generado.
- Soto_TrabajoFinal.Rproj: proyecto de RStudio.
- bases/: datos BACI 2024, clasificación HS22, versión V202601, y códigos de países y productos.

## Cómo reproducir el informe
1. Abrir Soto_TrabajoFinal.Rproj en RStudio.
2. Tener instalados los paquetes tidyverse, countrycode y knitr, además de Quarto.
3. Abrir Trabajo_Final.qmd y hacer clic en Render.

La base BACI está comprimida en formato .xz, sin pérdida de datos.
El código la lee directamente, sin necesidad de descomprimirla.
