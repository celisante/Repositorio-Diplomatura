**En cuanto a la estructura de la carpeta "Montano Enzo":**

- resultados: imagenes y excel.

- bases: CEPPI Y WDI.

- html como formato de salida.

- trabajo_final.rmd como codigo fuente en Rmarckdown donde se desarrolla todo el trabajo.
